# Open Finance Terminal Roadmap

## North-star

Build an open-source, AI-native financial terminal that helps people investigate markets and financial systems through reproducible data, transparent analysis, and source-grounded AI.

## Role inside Finance AI Lab

The terminal is a flagship engineering track.

### Market Watcher

Evidence-grounded teaching engine.

### Open Finance Terminal

Terminal-style research environment for market, macro, filings, news, analytics, and AI-assisted research.

### Money Pulse

Personal-finance and financial-wellness experiment.

These projects share:

- deterministic calculations;
- provenance;
- test fixtures;
- separation of facts and interpretations.

## Six build stages

### Stage 1 — Data shell

- command router;
- source adapters;
- entity lookup;
- canonical evidence schema.

### Stage 2 — Terminal surfaces

- quotes;
- historical charts;
- macro panels;
- filings;
- news/events;
- saved queries.

### Stage 3 — Analysis

- deterministic calculations;
- Python/SQL execution;
- comparison tables;
- chronology checks;
- exportable reports.

### Stage 4 — AI

- structured evidence bundles;
- tool-using research agent;
- citation verifier;
- uncertainty layer;
- prompt library.

### Stage 5 — Local-first

- Ollama/local model adapter;
- offline fixtures;
- local research workspace;
- explicit privacy modes.

### Stage 6 — Open ecosystem

- MCP server;
- plugin/provider interface;
- documented data contracts;
- contribution guide;
- benchmark/evaluation suite.

## First MVP boundary

Build:

command -> deterministic data -> normalized evidence -> human-readable answer

Only after this is reliable should the project add a general AI agent.

## Open-source references

- OpenBB ODP: data integration/platform architecture.
- OpenBB custom agents: agent patterns, MCP, citations, charts, and tables.

Learn from these projects without copying proprietary product identity or data.
